# Fair-PCM

Fair Possibilistic C-Means (Fair-PCM) — a fairness-regularized variant of
possibilistic c-means clustering.

## Objective

```
F(T, V) = Σ_ik t_ik^m ‖x_i − v_k‖²
        + Σ_k η_k Σ_i (1 − t_ik)^m
        + λ Σ_k KL( q̂_k ‖ p )
```

The first two terms are the standard possibilistic c-means objective
(a distance term plus a penalty term controlled by `η_k` that keeps
typicalities from collapsing to zero). The third term penalizes clusters
whose soft group composition `q̂_k` diverges (via KL divergence) from the
overall population's group proportions `p`, encouraging each cluster to
reflect the dataset's group balance.

## Quick start

```python
import pandas as pd
from fair_pcm import FairPCM

df = pd.read_csv("datasets/synthetic_blobs_2group.csv")
X = df[["x1", "x2"]].to_numpy()
S = df["S"].to_numpy()          # sensitive attribute, e.g. group A/B

model = FairPCM(n_clusters=3, m=2.0, lam=1.0, random_state=0)
model.fit(X, S)

print(model.labels_)            # hard cluster assignments
print(model.centers_)           # cluster centers
print(model.fairness_report(S)) # per-cluster KL divergence & soft group mix
```

Or run the bundled demo directly:

```bash
python examples/run_demo.py blobs_2group
python examples/run_demo.py blobs_3group
python examples/run_demo.py overlap
```

## Datasets

The `datasets/` folder ships three synthetic benchmarks generated by
`make_datasets.py`, each with imbalanced group proportions per cluster so
that fairness-vs-accuracy trade-offs are visible:

| File                             | Points | Blobs | Groups | Notes                              |
|-----------------------------------|:-----:|:-----:|:------:|-------------------------------------|
| `synthetic_blobs_2group.csv`      | 900   | 3     | A/B    | Skewed group mix per blob           |
| `synthetic_blobs_3group.csv`      | 1000  | 4     | A/B/C  | Three-way group imbalance           |
| `synthetic_overlap.csv`           | 840   | 2 + noise | A/B | Overlapping blobs + sparse outliers to test possibilistic noise robustness |

These are generated locally (no external downloads required) so the repo
runs end-to-end offline. To regenerate them:

```bash
python datasets/make_datasets.py
```

To benchmark against a real-world fairness dataset (e.g. UCI Adult, Bank
Marketing, COMPAS), drop the CSV into `datasets/` and use the
`load_real_dataset()` helper in `make_datasets.py`, which loads numeric
features into `X` and a chosen column into `S`.

## Algorithm notes

- **`m = 2` (default)**: typicality updates are solved in closed form via
  the depressed-cubic (Cardano / trigonometric) solver in
  `_solve_depressed_cubic`, which is fast and exact.
- **`m ≠ 2`**: falls back to a vectorised Newton iteration with a
  per-cell Brent's-method fallback (`_solve_general_m`) for cells where
  Newton stalls.
- `η_k` (the possibilistic penalty per cluster) is initialized from
  within-cluster variance of a k-means++ warm start.
- `λ` controls the strength of the fairness regularizer; `λ = 0` reduces
  to standard possibilistic c-means.
